# Умный список задач (Smart Todo)

Учебный проект по дисциплине «Проектный практикум».

Планировщик дел с категориями, приоритетами и автоматическим определением
даты выполнения из текста задачи на русском языке
(например, «завтра сходить к врачу в 15:00»).

Документация будет дополняться по мере разработки — см. папку `docs/`.
