# Журнал решений

Проект выполняется одним человеком, поэтому вместо протоколов митингов ведётся журнал ключевых решений: что решили, почему, какие альтернативы отклонили.

| № | Дата | Решение | Альтернативы | Обоснование |
|---|---|---|---|---|
| 1 | [дата] | Тема: **Умный список задач** | Агрегатор отзывов на игры, Трекер привычек | Минимум сущностей, нет внешних API с ключами, «нетривиальная» задача (NLP) закрывается библиотекой с поддержкой русского языка |
| 2 | [дата] | Backend на **FastAPI**, БД **SQLite** | Django + PostgreSQL | Меньше кода и настройки; Swagger из коробки; PostgreSQL легко включить через `DATABASE_URL` |
| 3 | [дата] | NLP: **регулярки + dateparser**, без ML | spaCy / Natasha / LLM API | Детерминированно, быстро, работает офлайн, покрывает целевые формулировки; отладка по тестам |
| 4 | [дата] | Хранить и `raw_text`, и `title` | Хранить только очищенное название | Возможность показать, что распознано, и переразобрать при улучшении парсера |
| 5 | [дата] | JWT в localStorage | Cookie-сессии | Проще для SPA и демо; риски XSS приемлемы для учебного проекта, отмечены в roadmap |
| 6 | [дата] | Отдельный эндпоинт `/api/tasks/parse` | Разбор только при создании | Живой предпросмотр без побочных эффектов — ключевая UX-фича |
| 7 | [дата] | Frontend: **React + Vite + Tailwind**, без UI-библиотеки | Vue, готовые компоненты (MUI) | Знакомый стек; собственные примитивы — меньше зависимостей и веса бандла |
| 8 | [дата] | `bcrypt` напрямую вместо `passlib` | passlib[bcrypt] | passlib 1.7 несовместим с bcrypt ≥ 4.1 |
| 9 | [дата] | Категория — одно поле, теги отложены | Отдельная таблица тегов many-to-many | Достаточно для MVP; теги — в бэклоге (B-17) |
| 10 | [дата] | Деплой на публичный сервер — вне MVP | Yandex Cloud сразу | Ограничение по времени; Docker-compose обеспечивает воспроизводимый запуск на любом сервере за один шаг |
| 11 | [дата] | Формат скоупов задач вычисляется на сервере | Фильтрация на клиенте | Единая логика «сегодня/просрочено» для списка и счётчиков, работает при росте данных |
