# Тестирование

## Автотесты

Расположение: `backend/tests/`. Запуск: `cd backend && pytest -q`. Тесты используют in-memory SQLite, внешних зависимостей нет.

| Файл | Что проверяет | Кол-во |
|---|---|---|
| `test_nlp.py` | 11 фраз с датами (относительные, дни недели в падежах, явные даты и время, части дня), 3 фразы без дат, перенос прошедшего времени на завтра | 15 |
| `test_auth.py` | Регистрация, дубликат email (409), короткий пароль (422), вход / неверный пароль (401), `/me` с валидным и битым токеном | 5 |
| `test_tasks.py` | Доступ без токена, извлечение даты при создании, приоритет явного `due_at`, предпросмотр, PATCH/toggle/DELETE, скоупы и статистика, категории и фильтры, изоляция данных между пользователями | 8 |

Итого: **28 тестов**. Запускаются в CI при каждом push (`.github/workflows/ci.yml`).

## Чек-лист ручного тестирования перед демо

### Аутентификация
- [ ] Регистрация нового пользователя → сразу на страницу задач
- [ ] Регистрация с занятым email → сообщение об ошибке
- [ ] Пароль из 3 символов → форма не отправляется / ошибка
- [ ] Вход существующего пользователя
- [ ] Вход с неверным паролем → «Неверный email или пароль»
- [ ] Перезагрузка страницы → сессия сохранена
- [ ] «Выйти» → страница входа; прямой переход на `/` → редирект на `/login`

### Умный ввод
- [ ] «завтра сходить к врачу» → предпросмотр «сходить к врачу · Завтра»
- [ ] «сдать отчёт в пятницу в 15:00» → «Пт, 15:00» (или дата, если пятница дальше 6 дней)
- [ ] «до понедельника подготовить доклад» → ближайший понедельник
- [ ] «созвон в 7 вечера» → сегодня 19:00 (или завтра, если время прошло)
- [ ] «5 октября в 10 утра встреча» → 5 окт, 10:00
- [ ] «купить молоко» → «дата не распознана»
- [ ] «прочитать 3 главы» → название не искажено, даты нет
- [ ] Клик по примеру под полем подставляет текст
- [ ] После «Добавить» поле очищается и получает фокус

### Список и фильтры
- [ ] Новая задача появляется в списке сразу
- [ ] Бейджи категории и приоритета отображаются
- [ ] Просроченная задача — красная рамка и подпись «просрочено»
- [ ] Вкладка «Сегодня» показывает только задачи с сегодняшним сроком
- [ ] Вкладка «Без даты» показывает только задачи без срока
- [ ] Вкладка «Выполненные» показывает только выполненные
- [ ] Фильтр по категории + приоритету + поиск работают вместе
- [ ] Кнопка «Сбросить» появляется при активных фильтрах и очищает их
- [ ] Клик по карточке-счётчику переключает вкладку

### Управление задачей
- [ ] Клик по кружку → задача зачёркнута, счётчик «Выполнено» +1
- [ ] Повторный клик → возвращается в работу
- [ ] «Изменить» → inline-форма; изменение названия, категории, приоритета, срока сохраняется
- [ ] Очистка поля срока в редактировании → задача без даты
- [ ] «Удалить» → диалог подтверждения; после подтверждения задача исчезает

### Устойчивость
- [ ] Остановить бэкенд → на странице сообщение об ошибке и кнопка «Повторить»
- [ ] Запустить бэкенд → «Повторить» загружает данные
- [ ] Второй пользователь не видит задачи первого

### Адаптивность
- [ ] Ширина 375 px: поля ввода во всю ширину, вкладки прокручиваются горизонтально, кнопки «Изменить/Удалить» видны
- [ ] Ширина 1280 px: контент по центру, максимум ~768 px

## Известные ограничения

- Парсер не понимает относительные фразы вида «на следующей неделе», «в конце месяца», «через полчаса».
- Время без предлога и суффикса («встреча 15 00») не распознаётся — только «в 15:00», «15:00», «в 3 дня».
- Нет e2e-тестов интерфейса (в roadmap — Playwright).
