## Слайд 2. Проблемная область

- Студент держит в голове дедлайны по 6–8 предметам, бытовые дела и подработку.
- Существующие планировщики требуют заполнять дату и время отдельными полями: 4–6 кликов на одну задачу. В результате задачи не записываются вовсе — остаются в заметках или в голове.
- [Результат опроса: ___ из ___ студентов ведут список дел; главное раздражение — «долго заполнять»].
- Todoist умеет разбирать дату из текста, но с русским работает частично и берёт деньги за напоминания.

Актуальность: люди пишут задачи так, как говорят — «до понедельника», «к четвергу», «в 7 вечера». Инструмент должен понимать именно это.

## Слайд 3. Предлагаемое решение

Одна строка — и задача со сроком:
> «сдать отчёт в пятницу в 15:00» → **сдать отчёт**, Пт 15:00

Ключевые возможности:
- Автоопределение даты и времени из текста на русском.
- Живой предпросмотр: видно, что распознано, до сохранения.
- Категории, приоритеты, вкладки «Сегодня / Просроченные / Предстоящие».
- Работает в браузере на телефоне и компьютере.

Преимущества: без обучения, бесплатно, открытый код, запускается на своём сервере.

## Слайд 5. Как работает разбор даты

Каскад из пяти шагов, каждый вырезает свой фрагмент:

1. Явная дата `30.09`, `30.09.2026`
2. Явное время `в 15:00`, `в 7 вечера`, `к 12 дня`
3. День недели в любом падеже `до понедельника`, `к четвергу`
4. Часть дня `утром` → 09:00, `вечером` → 18:00
5. Остаток → `dateparser` (`завтра`, `через 2 дня`, `5 октября`)

Что осталось — название задачи. Покрытие: 15 автотестов, 19 из 20 демонстрационных фраз распознаются верно.

## Возможные вопросы на защите и ответы

- **Почему не нейросеть для разбора дат?** Детерминированный подход быстрее, работает офлайн, не требует ключей и легко тестируется; LLM — избыточен для узкой задачи.
- **Почему SQLite?** Ноль настройки для MVP; переход на PostgreSQL — одна переменная окружения, ORM не привязан к диалекту.
- **Как обеспечивается безопасность?** bcrypt для паролей, JWT с истечением, фильтрация задач по владельцу, CORS по белому списку.
- **Почему нет деплоя?** Ограничение по времени; Docker-образы собираются в CI, деплой — первый пункт roadmap.
- **Как масштабировать?** Stateless API за Nginx — можно поднимать несколько инстансов; БД вынести в PostgreSQL.
